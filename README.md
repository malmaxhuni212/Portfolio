# Mal Maxhuni | Interactive 3D Digital Portfolio

**Live Portfolio:** [https://portfolio-g89t.vercel.app/](https://portfolio-g89t.vercel.app/)

## Overview

An interactive 3D digital portfolio showcasing my work and professional journey at the intersection of **technical execution** and **growth marketing**.

Rather than a static resume, this project is built as a continuous 3D scroll-driven experience where visitors travel along a spline camera path through key stations:

- **Welcome & Introduction:** An interactive 3D scene featuring a custom React Three Fiber robot that greets visitors alongside a concise professional overview.
- **Career Overview & Experience:** Highlights from my 3+ years of experience across **founder**, **freelance**, and **full-time** roles (including **Risidio / Lunim**, **Mavix**, and **Freelance Growth Marketing**) and 300+ delivered projects.
- **System Logic & Methodology:** A breakdown of how I dissect business logic, apply Agile project management with real-time testing, and integrate modern AI tools and automations to drive practical business growth.
- **Credentials & Recommendations:** Academic background, specialized certifications in AI and digital marketing, and client/leadership endorsements.
- **Direct Communication Pipeline:** An interactive terminal-style contact interface powered by Formspree.

## Tech Stack

- **Frontend:** React 19, Vite
- **3D & WebGL:** Three.js, `@react-three/fiber`, `@react-three/drei`, `@react-three/postprocessing`
- **Styling & UX:** Custom Glassmorphic CSS, responsive desktop and mobile touch-snap layouts, smooth damped scroll physics

## Running Locally

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
